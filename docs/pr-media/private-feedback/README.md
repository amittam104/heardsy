# Private feedback walkthrough

All captures use a disposable Acme billing app and fictional reviewer/reporter accounts.

- [Submission](submission.png): the embedded widget with app-prefilled contact details and an attached invoice screenshot, without a Heardsy sign-in.
- [Private review](review.png): the saved screenshot, app metadata, internal note and status history in the workspace dashboard.
- [Customization](customization.png): separate private-widget settings for logo, theme, accent, launcher, placement and size, beside the live preview.
- [37-second walkthrough](walkthrough.mp4): report an invoice export problem, submit a screenshot, open the report in the private inbox, then add an internal note and mark it under review.
